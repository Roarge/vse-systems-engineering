# Writing Style

Applies to all prose produced in this repository: wiki pages, skill
bodies, methodology sections, templates, documentation, commit bodies,
and pull request text.

- UK English throughout (organisation, behaviour, modelling, defence,
  colour, licence as noun, practise as verb, analyse, programme).
- Never use em-dashes. Restructure with commas, parentheses, or
  "that is".
- Never use semicolons in body text. Split into two sentences.
- Never use contractions (write do not, cannot, will not, it is).
- Plain language first. Specialist terms get a one-line gloss on first
  use. The audience is cross-disciplinary.

Exception: bibliographic titles and verbatim quotations reproduce their
source's punctuation exactly, including em-dashes in ISO standard
titles.
